This repsitry contains the following list of items that will allow you to execute our workflow:

MCSI calculation – Matlab scripts that compute multi‑component shape invariants from images of hexagonally packed cylindrical, concentric‑cylindrical, and fractal architectures (pattern‑generation scripts are included).
Experimental data processing – Raw measurements, plus scripts that organize the data by architecture and derive the relevant mechanical properties. Experimental raw data can be obtained upon request to [thevamaran@wisc.edu](thevamaran@wisc.edu).
Model training – A ready‑to‑use dataset and an ANN optimisation script for training and evaluating the model.

Please use a MatLab 2023 to execute the scripts. 

The experimental data and the codes are original works by Thevamaran Lab at UW-Madison intended for scientific research purposes. Please do not share these on other platforms.

For queries reach out to Prof. Ramathasan Thevamaran ([thevamaran@wisc.edu](thevamaran@wisc.edu)) or graduate student Bhanugoaban Maheswaran ([bhanugoban@wisc.edu](bhanugoban@wisc.edu)).
